# Antislop Audit 001 (2026-11-24)

Target: **AudioExtract** (Video to Audio Converter, audited from git `HEAD` commit `fc3831c`)
Mode: `after` (global preference)

> Note: The current working tree contains uncommitted files from an unrelated project (`kaido-rush-32`) that replaced the committed Video to Audio Converter files. No source files were modified by this audit.

## Findings

1. **[HIGH | R-25]** Normal and large text contrast fail WCAG AA in light and dark themes: `--text-tertiary-light` (`#94a3b8`) on `#ffffff` is 2.56:1 (FAIL), `--text-tertiary-dark` (`#64748b`) on `#111827` is 3.73:1 (FAIL), and `--color-success-light` (`#059669`) on `#ecfdf5` is 3.58:1 (FAIL).
2. **[HIGH | R-03]** Interactive tap targets fall below the 44x44px minimum on touch devices: `.player-play-btn` / `.player-mute-btn` (28x28px), `.btn-icon` (34x34px), `.action-btn` (36x36px), `.theme-btn`, and `.btn-close-banner`; hero typography uses fixed `2.15rem` without fluid scaling for narrow viewports.
3. **[HIGH | R-39]** Accessibility semantics and reduced-motion gaps: `DropZone.tsx` uses a clickable `<div role="button">` instead of a native control, icons inside icon-only buttons omit `aria-hidden="true"`, `cursor: pointer` is repeated per-class instead of set in the base layer, and animations (`.btn-cta-pulse`, `.status-loading`, `.spin-icon`, `canvas-confetti`) ignore `prefers-reduced-motion: reduce`.
4. **[HIGH | R-40]** `BatchItem.tsx` renders `<img className="item-thumbnail">` without explicit `width` and `height` attributes, risking layout shift when thumbnails resolve asynchronously.
5. **[HIGH | R-37]** No `DESIGN.md` or explicit visual direction was established prior to styling, resulting in a sterile default (flat white/slate, default `#2563eb` blue accent, system font stack, uniform cards).
6. **[MEDIUM | R-01, R-13, R-19]** Generic blue-to-indigo gradient on `.logo-icon-wrapper`, decorative glow on `.status-dot.status-ready`, and an endless infinite `pulse-cta` animation loop on `.btn-cta-pulse` have no documented UX or hierarchy purpose.
7. **[MEDIUM | R-04]** `Sparkles` (a generic AI icon) is used in `BatchItem.tsx` and `InfoModal.tsx`, and the icon set lacks a written relevance rationale.
8. **[MEDIUM | R-09]** The header stacks four pill/capsule badges (`Pro`, `100% Private & Local`, `Saved in Browser`, `Wasm Engine Ready`), combining capsule shape, thin borders, status dot, and uppercase styling.
9. **[MEDIUM | R-10, R-12]** Glassmorphism (`backdrop-filter`) is used on header, modal backdrop, and thumbnail badges, while uniform `--shadow-sm` and `--radius-lg` across every card flatten visual elevation.
10. **[LOW | R-16, R-20]** Generic marketing copy ("Instant Video to Audio Converter", "studio-grade", "Pro") and generic SaaS layout lack a distinctive audio-workbench identity; swapping the logo makes it indistinguishable from any upload form.
